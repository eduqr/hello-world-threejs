## hello world threejs!

Earlier this year I wanted to learn more about Three.js because I've always been interested in how people create really cool things with it. Also, ai agents seem to love using it nowadays, so it's important to (at least) know the basics. That's why I created this project to experiment with it.

The experiments here are pretty simple. The [manual](https://threejs.org/manual/) and the [docs](https://threejs.org/docs/) helped me a lot.

I hope you give it a try. I'll definitely use it in future projects.

You can check out the experiments here: https://hello-world-threejs.netlify.app/
